# assets: pictures, video and scans

| Folder | Contents |
| --- | --- |
| `shreyas/` | Photos of Shreyas |
| `videos/` | `oncure.mp4` |
| `certificates/` | Real certificate scans, named after the award id (for example `psat.jpg`) |
| `journey/` | Placeholder illustrations (`*.placeholder.jpg`) to replace with real photos |
| `house/` | Furniture, textures and sky for the Creative 3D house (CC0, credits in `house/ASSETS.md`) |

Run `pnpm assets` to see every file and where it is used. To replace a picture, save the new one
with the same name. Never add anything showing his email, phone, address or birth date.

Guide: [docs/2-change-content.md](../../docs/2-change-content.md)
