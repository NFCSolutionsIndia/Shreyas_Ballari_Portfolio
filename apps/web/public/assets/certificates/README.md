# Certificate scans

Put real certificate scans here as `.jpg`, named after the award's `id` in
`src/content/portfolio.ts`:

`cbnrp.jpg` · `honors.jpg` · `psat.jpg` · `map.jpg` · `arrow.jpg` · `authors.jpg` · `minimed.jpg`

A scan replaces the designed certificate card in the Classic awards stack. Without one, the
designed card shows. Cover any address, email, phone number or birth date before adding a scan.
